# Assinatura de e-mail · Nojosa Advocacia

- `assinatura.html`: assinatura pronta (Gustavo Nojosa). Abra no Chrome, selecione tudo (Cmd+A), copie e cole nas configurações de assinatura do Gmail ou Outlook.
- `index.html`: gerador com formulário para outras pessoas da equipe.
- Imagens: `logo-nojosa-claro.png`, `icone-phone.png`, `icone-mail.png`, `icone-site.png`, `icone-linkedin.png`, `icone-instagram.png`.
- `assinatura-previa.png`: prévia visual.

As imagens são carregadas de `https://raw.githubusercontent.com/nojuridico/claude/main/assinatura-email/`. O repositório precisa ser público e a pasta deve se chamar `assinatura-email` na branch `main`.
